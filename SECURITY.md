# Segurança do 6DNX

Não publique chaves, senhas, capturas com credenciais ou detalhes exploráveis
em uma issue pública.

Para relatar uma falha, use o atendimento privado indicado no próprio site e
identifique a mensagem como **RELATO DE SEGURANÇA**. Inclua somente o necessário
para reproduzir o problema. Tokens eventualmente expostos devem ser revogados e
substituídos; apagar a mensagem ou o arquivo não invalida uma credencial.

O repositório não recebe executáveis de produtos. O site publica catálogo,
conteúdo e rotas de atendimento. Pagamentos só podem ser considerados
confirmados após validação humana ou webhook autenticado e idempotente.
